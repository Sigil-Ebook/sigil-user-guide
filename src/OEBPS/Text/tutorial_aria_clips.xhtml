Add Accessible Notes With Aria Clips

— Footnotes, Endnotes and Page Breaks —

Aria Clips are a ready-made set of Clips for accessibility. They insert the markup that screen readers and reading systems expect for footnotes, endnotes, page breaks, sections and asides: the correct elements, epub:type and role attributes, IDs, links and labels.

Aria Clips work like ordinary Clips, with one extra feature: they can take a note number from the text you have selected and use it in every place where the markup needs it.

Where to Find Aria Clips

  • Use Insert=>Aria Clip... or the Insert Aria Clip button on the Insert toolbar.

  • Aria Clips are only available in Code View and only for EPUB3 books.

  • If you use them often, assign a keyboard shortcut to MainWindow.InsertClip in Preferences=>Keyboard Shortcuts.

The Add Aria Clips dialog lists all clips by name, followed by a short code in brackets, for example Reference to Footnote (fn_ref). When you select a clip, the dialog shows the markup it will insert. Double-click a clip, or select it and click OK, to insert it.

How Your Selection Is Used

Before you open the dialog, select some text in Code View. What happens to the selection depends on the clip:

  • Clips that wrap the selection (for example Aside, Section, Footnote in aside): the selected text is placed inside the new markup.

  • Clips that replace the selection (Reference to Footnote, Reference to Endnote, Backlink from Footnote, Backlink from Endnote, PageBreak in span): the selected text is removed and only the clip is inserted. These clips are meant for selecting just the note marker or page number.

  • Clips with no selection (Section: Endnotes, PageBreak in hr): use these with nothing selected. If you select text first, it will be replaced by the clip.

The Note Number

The footnote, endnote and page break clips contain a number placeholder. Sigil looks for a number at the very beginning of your selection. The number may be in square brackets and may be followed by a full stop. Spaces before the number are ignored.

For example, all of these selections give the number 3:

3
[3]
3.
[3] This is the text of the note.
3. This is the text of the note.

These selections do not give a number:

(3)
¹  (a superscript character)
*
Note 3
<p>3. This is the text of the note.</p>  (the selection starts with a tag)

If no number is found, the clip is still inserted, but the placeholder _N_ is left in the IDs, links and labels, for example id="fn_N_". You can then type the number yourself, or undo with Ctrl+Z and select the text again.

Only the number is used, so the selection 12a gives 12, and with a replacing clip the letter is lost. Check the result after inserting.

Example: Footnotes in a Chapter

Suppose a chapter contains a note marker in the text and the note at the end of the chapter:

<p>The ship left the harbour at dawn[1] and sailed north.</p>
...
<p>[1] In the summer, dawn there is before four o'clock.</p>

1. The Reference

In Code View select [1] in the text (only the marker, not the words around it) and insert Reference to Footnote. The marker is replaced with:

<a id="ref_fn1" href="#fn1" epub:type="noteref" role="doc-noteref" aria-label="To footnote 1">[1]</a>

Selecting only 1 gives the same result. The link text is always the number in square brackets; you can change it afterwards, for example to a superscript number.

2. The Note

Select the text of the note, starting with its number: [1] In the summer, dawn there is before four o'clock. Do not include the <p> tags, otherwise the number cannot be found. Then insert Footnote in aside:

<p><aside id="fn1" epub:type="footnote" role="doc-footnote">
  <p>[1] In the summer, dawn there is before four o'clock.
    <a href="#ref_fn1" epub:type="backlink" role="doc-backlink">Back to [1]</a>
  </p>
</aside>
</p>

The clip replaces only what you selected, so the original <p> and </p> are still around the new aside. Delete them: an aside (or a paragraph) is not allowed inside a paragraph.

The number stays in the note text, and the backlink adds Back to [1]. Edit the text as you like; the IDs and links are already correct.

3. Group the Notes (Optional)

Select all the notes at the end of the chapter (this time including their tags) and insert Section: Footnotes. It wraps them in:

<section epub:type="footnotes" aria-label="Footnotes">
  ...
</section>

There are three footnote clips: Footnote in aside, Footnote in div and Footnote in p. They differ only in the element used for the note. With Footnote in p it is especially important to remove the old paragraph tags, otherwise you get a paragraph inside a paragraph.

Footnote IDs only need to be unique within one file, so footnotes numbered from 1 in every chapter are fine.

Example: Endnotes in a Separate File

Endnotes are usually collected in one file, for example notes.xhtml, and numbered through the whole book. The reference is in a chapter file and the note is in the notes file, so the links must include the file name. The endnote clips contain two placeholders for this:

  • HREF_TO_ENDNOTE in the reference: the path from the chapter to the notes file, for example notes.xhtml (or ../Text/notes.xhtml if the files are in different folders).

  • HREF_RETURN_FROM_ENDNOTE in the note: the path back to the chapter file that contains the reference, for example chapter03.xhtml.

Sigil cannot know these paths, so you must replace the placeholders yourself. If your Sigil interface is in another language, the placeholders are shown translated into that language.

1. The References

In chapter03.xhtml select the marker 17 and insert Reference to Endnote:

<a id="ref_en17" href="HREF_TO_ENDNOTE#en17" epub:type="noteref" role="doc-noteref" aria-label="To endnote 17">[17]</a>

Replace HREF_TO_ENDNOTE with notes.xhtml. When all references are inserted, you can do this for the whole book at once with Find & Replace, searching All HTML Files.

2. The List of Notes

In notes.xhtml, with nothing selected, insert Section: Endnotes. It creates an empty numbered list:

<section epub:type="endnotes" role="doc-endnotes">
  <ol>
  </ol>
</section>

Move the text of each note into the list, one note per line, without <p> tags.

3. Each Note

Select one line, starting with its number, for example 17. The letter was never sent., and insert Endnote in li:

    <li id="en17">
      <p>17. The letter was never sent.
        <a href="HREF_RETURN_FROM_ENDNOTE#ref_en17" epub:type="backlink" role="doc-backlink">Back to [17]</a>
      </p>
    </li>

Replace HREF_RETURN_FROM_ENDNOTE with the file that contains reference 17, here chapter03.xhtml.

An ol list numbers its items automatically, so a number kept in the note text is shown twice. Remove the number from the text, or hide the list numbers with CSS, for example ol { list-style-type: none; }.

All endnotes in one file need different numbers, because the number becomes the ID of the note (en17). If the endnotes of each chapter start again at 1, the IDs in the notes file will be repeated and the book will not validate. In that case renumber the notes through the whole book, or give the IDs a chapter prefix by hand (for example en3-1) in both the reference and the note.

Page Breaks

  • PageBreak in span: select a printed page number, for example 23, and insert the clip. The number is replaced by an invisible page marker: <span id="page23" epub:type="pagebreak" role="doc-pagebreak" aria-label="Page 23" />

  • PageBreak in hr: inserts <hr epub:type="pagebreak" role="doc-pagebreak" /> with no number. Use it with nothing selected.

Sections and Asides

  • Section and Aside: wrap the selected text. A second dialog lets you choose a role (for example Chapter, Dedication, Epigraph), and Sigil adds the matching epub:type and role.

  • Section: Chapter: wraps the selection in a chapter section with its own heading, <h1 id="heading1">CHAPTER_TITLE_HERE</h1>. Select the chapter content below the existing heading, then replace the placeholder with the title and delete the old heading. If you use this clip more than once in the same file, change the ID heading1 (in both the heading and aria-labelledby) so that it is unique.

  • Aside: Sidebar and Aside: Tip: wrap the selection in an aside labelled as a sidebar or a tip.

Labels and Language

Text that readers or screen readers will meet, such as To footnote, Back to, Footnotes or Page, is written in the language of the book, not the language of Sigil's interface. Sigil uses the language set on the html element of the current file or, if there is none, the first dc:language in the OPF, and takes the words from its own translation for that language. If Sigil has no translation for that language, the words are in the language of Sigil's interface.

Placeholders that you have to replace (HREF_TO_ENDNOTE, HREF_RETURN_FROM_ENDNOTE, CHAPTER_TITLE_HERE) are shown in the language of Sigil's interface.

Check Your Work

  • Search the book for _N_ to find clips that were inserted without a number.

  • Search for HREF_ to find endnote links that still need a file name.

  • Click a few references and backlinks in Preview to test them, and run a validation (for example the EpubCheck plugin) to find broken links and repeated IDs.
