Installation

— Getting Started —

You can download the latest version of Sigil from the official Sigil web site and install it for your OS.

Windows

Sigil is supported on Windows 10 and later.

  • Download Sigil for Windows

Double-click the file to run the installer, e.g.:

  • Sigil-2.8.5-Windows-x64-Setup.exe

Mac

Sigil is supported on MAC OS 13 x86_64 bit Intel and Arm64 or later

  • Download Sigil for MAC

Unpack the TXZ file and drag the “Sigil.app” file to your Applications folder, e.g.:

  • Sigil.app-2.8.5-Mac-arm64.txz
  • Sigil.app-2.8.5-Mac-x86_64.txz

Linux

To better support Linux uers, Sigil releases an AppImage that should work on most x86_64 Linux distributions. Unlike Linux Distribution based versions of Sigil, our AppImages are feature for feature matched with our MacOS and Windows releases and include all of the pieces needed to successfully run all of the features of Sigil including plugins.

  • Download Sigil AppImage for Linux x86_64

Just download tha AppImage and give it execution permissions and when launched it should just work.

  • Sigil-2.8.5-x86_64.AppImage
  • Sigil-2.8.5-x86_64.AppImage.zsync

Of course since the source code is freely available, you can of course build from source for your version of Linux or cpu.
